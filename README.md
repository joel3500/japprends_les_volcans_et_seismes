# Volcans, séismes et phénomènes naturels 🌋

Quatre jeux éducatifs gratuits, adaptés à chaque âge (3 à 17 ans), disponibles
en 7 langues (FR/EN/ES/DE/IT/AR/ZH) via le sélecteur en haut de chaque page.

## Les 4 activités
- 🐣 `tier_3_6.html` — Volcans, séismes et phénomènes naturels (3-6 ans)
- 🧭 `tier_7_10.html` — Le jeu des volcans et des séismes (7-10 ans)
- 🧠 `tier_11_13.html` — Défi des volcans et des séismes (11-13 ans)
- 🎓 `tier_14_17.html` — Défi avancé de géologie : volcans et séismes (14-17 ans, secondaire/lycée/cégep)

## Déploiement
Pousse ce dossier dans un dépôt GitHub nommé `japprends_les_volcans_et_seismes`, puis active
GitHub Pages, puis déploie sur Netlify pour l'URL finale
(`japprendslesvolcansetseismes.netlify.app`).
